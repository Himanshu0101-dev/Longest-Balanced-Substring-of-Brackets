# Longest-Balanced-Substring-of-Brackets
You are given a string consisting of only three types of brackets:  Round brackets ()  Square brackets []  Curly brackets {}
Your task is to find the length of the longest balanced substring.
A substring is considered balanced if:

Every opening bracket has a corresponding closing bracket of the same type.

Brackets are properly nested.

Return the maximum length of such a substring.

Constraints:

Input string length ≤ 10^5

String contains only ()[]{} characters
